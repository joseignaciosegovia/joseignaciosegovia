## Proyecto destacado

### [Sports Court Booking](https://github.com/joseignaciosegovia/sports-court-booking)
Aplicación web para reservar pistas deportivas de un municipio. Los clientes reservan y pagan online, y el personal gestiona pistas, reservas y cancelaciones desde una intranet.

- Pagos con **Stripe Checkout**, webhooks y reembolsos automáticos
- Roles de usuario: cliente, gestor y administrador
- Calendario por pista con reprogramación arrastrando (FullCalendar)
- **367 tests automatizados (94 % de cobertura)** y CI con GitHub Actions
- Los tests destaparon bugs reales (pagos tardíos, dobles reembolsos, solapamientos), documentados en el README del proyecto

[Ver código](https://github.com/joseignaciosegovia/sports-court-booking) · [Ver demo](https://sports-court-booking-1.onrender.com/)
